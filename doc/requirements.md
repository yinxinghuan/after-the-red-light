# Requirements

## 1. Overview

《红灯熄灭以后》是一款中文/英文双语、单人、轻量持续叙事 RPG。玩家是被暴雨困在精品旅馆里的成年旅客；单次游玩约 10–15 分钟，以一个可暂停的小章节结束，线索、地点、物品和人物关系跨次保留。玩家反复进行交谈或试探、检查矛盾、移动、设定边界、使用有限物品和撤退；每次行动必须产生可见后果和新的具体选择。第一行动承诺是发现“手中房卡与旅馆说法矛盾”；首段承诺是认识至少一位可持续互动的成年人并找到一条关于不存在房间的可靠线索；回访理由是追查旅馆结构、人物秘密和玩家选择形成的关系。

所有持续角色均明确成年。允许暧昧、调情、亲密距离与成人欲望，但不生成露骨性行为、未成年人、乱伦、性侵或被迫性行为；玩家的拒绝、暂停和保持距离必须立即生效，不能因此丢失主线进度或遭到关系惩罚。

## 2. Visual Design

竖向移动端优先的累积阅读界面，正文与事件图按时间沉积，顶部三项状态保持安静，仅在真实变化时反馈。世界使用褪色精品旅馆编辑插画：暗红绒面、烟草象牙色、失去光泽的黄铜、雨夜窗户和局部红灯。普通场景保持第一/第三人称均衡；重要对话优先第一人称看见对方表情，新地点使用第三人称建立空间。素材包括横向入口图、方形封面、1024×1024 英文海报、角色表情图、地点图和物品图。

## 3. Game Mechanics

- 核心循环：选择具体行动 → 权威状态更新 → 正文说明可感知后果 → 0–5 个与现场一致的后续行动；快捷选项全部被移除时，自由输入仍是可见且可用的出口。
- 系统推荐若未能产生可验证结果，当前回合不提交数值、物品、时间、地点或事件变化；该推荐立即从快捷选项中退场，只保留仍可信的同级行动。系统不得用“查看现在能做的事”“放弃原计划”或当前长期目标重新凑出一个恢复菜单。
- 作者预设行动只在声明的地点、人物或阶段条件内成立；同一句固定行动离开适用现场后不能作为全局口令再次触发。没有权威进展时，系统也不得把刚完成的行动改写成“再检查 / 再触摸 / 继续观察同一对象”重新推荐。
- 镇定：0–100，初始 68；危险、误导和独处会降低，安全的公开空间、主动撤退或明确休息可恢复。30 以下进入警告；0 时只能执行确定性撤退/恢复动作。
- 欲念：0–100，初始 22；玩家主动靠近、调情或接受亲密承诺时上升，设定距离或辨认幻觉时下降。65 以上会提高诱惑型危险强度，85 以上可能让不可靠线索显得可信，但不会夺走拒绝权。
- 线索：0–8，初始 0；可靠证据才增加。不会因失败减少；达到 3 后可以辨认旅馆第一层谎言，达到 6 后允许进入章节收束。
- 红色火柴册：初始 3 根。玩家明确选择点燃时才消耗 1 根；它揭露一个被黑暗隐藏的细节，同时镇定 -4、线索 +1。询问、查看或考虑使用不会消耗。
- 小地图包括大厅、丝绒酒廊、二层走廊、玩家房间、地下洗衣房和屋顶玻璃房；不存在的九号房只能在可见证据成立后加入地图。
- 危险采用警告 → 对峙 → 结算；无身体战斗。玩家可说出变化、进入有人的亮处、或明确点燃一根红色火柴。火柴等本地权威行动必须在结算物品与数值的同一回合推进当前危险阶段，不能把玩家送回相同选项。模型生成及一次修复仍无法维持同一威胁时，本地状态机直接写出该阶段的可见结果并继续推进；失败留下镇定损失、时间推进、路线封闭或关系事件，不删除存档。
- 拒绝亲密是正常策略：即时停止该互动、欲念降低，并保留调查与关系的其他可行方向。
- 没有固定五回合结束。找到 3 条可靠线索并处理第一次九号房邀请后出现可继续的章节暂停点，不锁死世界。

待验证实验：连续 12 个推荐选项中，至少 10 个应能由当前正文或权威状态直接解释；不得出现重复刚完成行动、语义改写后的同义重试、笼统“观察变化”、无根据人物或跨地点断头路。连续拒绝两个不可靠推荐时，选项集合必须单调缩小，不能重新生成相同集合；旧版恢复循环存档读入后必须一次迁移并保持幂等。

## 4. Controls

- 触控/鼠标点击横向快捷选项执行行动；可滚动选项使用 `onClick`。
- 文本框允许自由输入任何行动；Enter 提交，Shift+Enter 换行。
- 顶部文字、音频、关系/世界入口均为至少 44×44 CSS px 的 SVG 控件。
- 数字快捷键只在平台实际支持且不会与输入框冲突时启用；移动端不依赖悬停。

## 5. Win / Lose Conditions

没有传统 Game Over。镇定归零会触发确定性撤退/恢复门禁；欲念过高会提高误导风险但不取消玩家选择；火柴耗尽只关闭一种验证方式。危险阶段不允许反复出现“查看当前能做的事 → 返回同一组危险选项”的闭环；普通推荐无法可靠推进时，该推荐被隔离且不会重复扣数值，若没有可信快捷选项则保留自由输入而不伪造按钮。已保存在旧恢复循环中的玩家读档后自动移除失败行动和合成恢复菜单。第一章节在玩家处理九号房的第一次邀请后形成可继续的暂停点。玩家可随时重开世界，重开需要确认且只清除此游戏存档。

## 6. Sound Effects

- 普通选择：80–120 Hz 的低幅黄铜触点，70–110 ms。
- 可靠线索：440/554 Hz 两音上行，160 ms，总音量低于 0.25。
- 红灯熄灭：48 Hz 低脉冲叠加 1.2 kHz 极短灯丝声，220 ms。
- 设定边界成功：柔和 196 Hz 单音，120 ms，不使用奖励式欢呼。
- 危险失败：70–55 Hz 下滑，240 ms；不使用尖叫或突发高音伤害玩家。
- 环境：48 BPM，雨声、通风低鸣和稀疏钢琴音程；首次手势后解锁，静音、后台和音频失败均不阻塞游戏。
